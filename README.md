# Raven-Club — Football Prediction Platform

Онлайн-платформа для футбольного менеджменту та спортивних прогнозів. Користувачі створюють ліги, запрошують учасників, роблять прогнози на матчі та змагаються за місце в таблиці лідерів.

🔗 **Демо:** [crow-club-nginx.rtot74.easypanel.host/leaderboard](https://crow-club-nginx.rtot74.easypanel.host/leaderboard/)
Проєкт розгорнутий на сервері з використанням Easypanel.

## 🧩 Функціонал

- **Ліги** — створення приватних і публічних ліг, запрошення учасників, налаштування власних правил нарахування балів для кожної ліги
- **Турніри та тури** — структура: ліга → турнір → тур → матчі, з дедлайном на подачу прогнозів для кожного туру
- **Прогнози** — користувачі прогнозують рахунок матчу до дедлайну; після дедлайну тур блокується (`is_locked`) і нові прогнози заборонені
- **Автоматичне нарахування балів** — після внесення адміном офіційного результату матчу Django-сигнал автоматично запускає Celery-задачу підрахунку балів для всіх прогнозів на цей матч
- **Перерахунок результатів** — якщо результат матчу було виправлено (VAR, технічна поразка тощо), система автоматично скидає й перераховує бали
- **Таблиця лідерів** — оновлюється за розкладом (кожні 5 хв) через Celery Beat, з денормалізованими полями для швидкого відображення рейтингу
- **Нагадування** — розсилка нагадувань користувачам за годину до дедлайну туру, якщо прогноз ще не зроблено
- **Адмін-панель** — на базі `django-unfold` із кольоровими бейджами статусів та кастомними діями ("Нарахувати бали", "Заблокувати тур" тощо)

## 🛠 Технологічний стек

**Backend**
- Django 5.x, Python 3.12
- PostgreSQL 16 (UUID primary keys, JSONField)
- Redis — брокер для Celery та кеш
- Celery 5 + django-celery-beat — фонові задачі та розклад
- django-unfold — адмін-панель

**Frontend**
- Django Templates (серверний рендеринг)
- HTMX — динамічні елементи без SPA
- Alpine.js — легка клієнтська логіка
- Tailwind CSS

**DevOps**
- Docker + docker-compose (postgres, redis, celery worker, celery beat, web)
- Nginx
- django-environ, Whitenoise
- Деплой на сервер через Easypanel

## 🗂 Структура проєкту

Кожен Django app відповідає за окрему предметну область:

| App | Відповідальність |
|---|---|
| `users` | реєстрація, авторизація, ролі |
| `leagues` | ліги, учасники, правила нарахування балів |
| `tournaments` | турніри, тури, матчі |
| `results` | еталонні результати матчів |
| `predictions` | прогнози користувачів |
| `leaderboard` | таблиця лідерів |
| `notifications` | нагадування та сповіщення |

## 🗄 Схема бази даних

9 таблиць у 5 логічних групах: користувачі, ліги/учасники/правила, турнірна структура (турніри/тури/матчі), еталонні результати, прогнози. Первинні ключі — UUID, зв'язки — за нотацією Crow's Foot.

## 🚀 Запуск проєкту

```bash
git clone https://github.com/DmitriyViatkin/Raven-Club.git
cd Raven-Club

docker-compose up --build
```

Піднімаються сервіси: `web` (Django), `db` (PostgreSQL 16), `redis`, `celery_worker`, `celery_beat`.
